Use `PlateFrame` for real structural chrome — sidebars, rails, the board bezel.

```jsx
<PlateFrame corner="top-right" style={{ width: 328 }}>
  <StatBar label="ALIGNMENT" value="87" unit="%" fill="aligned" />
</PlateFrame>
```

Never as a hero graphic on its own: the plate is texture on a panel that has a job, not decoration.
