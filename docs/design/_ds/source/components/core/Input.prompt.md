Use `Input` for every field.

```jsx
<Input label="Team email" defaultValue="coach@aod.gg" />
<Input label="Absence threshold" mono width="88px" unit="seconds of dead air" defaultValue="4.0" />
```

Always recessed — an input that floats above the plate contradicts the elevation system. Focus lights the border red; no glow, no ring. Set `mono` whenever the value is a measurement.
